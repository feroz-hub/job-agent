# Feroz Job Agent

An AI-assisted job discovery and application workflow built with Python.

## Goal

Build a system that can:

- Discover relevant jobs from multiple job portals
- Filter jobs based on target roles and location
- Compare job descriptions against a candidate profile
- Generate an AI match score
- Track applications
- Tailor resumes for relevant jobs
- Assist with job applications
- Monitor recruiter responses

## Planned Flow

Job Boards
    ↓
Job Discovery
    ↓
Filtering & Deduplication
    ↓
AI Job Matching
    ↓
Application Tracking
    ↓
Resume Tailoring
    ↓
Application Assistant
